# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub private vulnerability
reporting: open this repository's **Security** tab and choose **Report a
vulnerability**. Do not open a public issue, pull request or discussion for a
security problem.

Useful reports name the affected skill or template, the version (the `vX.Y.Z`
tag, or the `version` in `.claude-plugin/plugin.json` / `package.json`), and the
steps or prompt that reproduce the problem.

## Supported versions

Fixes land on `main` and ship in the next `vX.Y.Z` tag. Only the latest tag
and `main` receive security fixes; older tags do not get backports. Update the
plugin to the latest version to pick up a fix.
